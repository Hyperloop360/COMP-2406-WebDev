Paws & Claws - COMP2406 Assignment 2

HOW TO RUN
1. Open a terminal in this folder.
2. Run: node server.js
3. Open http://localhost:3000 in a browser.
Applications are stored in memory only, so restarting the server clears them.

ACKNOWLEDGEMENTS
- Pet images were supplied with the assignment (created with openart.ai).
- Banner and whyAdopt images were generated with Gemini.
- Page text was generated by ChatGPT.

EXTRA FEATURES / DESIGN DECISIONS
- Shelters are loaded from every .json file in data/shelters/, so new shelters
  can be added without changing any code.
- The server only serves files from /styles, /js and /images, and it rejects
  invalid data (bad status, unknown pet or shelter).
- Status dropdowns on the Applications page are colour-coded:
  grey = Unprocessed, yellow = Pending, red = Rejected, green = Approved.
- Errors from the server are shown on the page instead of failing silently.

NOTES FOR THE TA

  then open View Applications to see them.
